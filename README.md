# Pathology Lab Management System

A menu-driven, command-line application written in Python that manages the day-to-day workflow of a small pathology laboratory: registering patients, booking tests, collecting samples, generating reports, and billing.

## Features

- Register patients and list all registered patients
- View the catalog of available tests with prices
- Book a test for a patient
- Track a booking through its lifecycle: `Sample Pending` → `Sample Collected` → `Report Ready`
- Enter test results and view the final report
- List all bookings with their current status
- Generate a bill (itemised, with total) for a patient

## Project Structure

```
.
├── main.py           # Entry point; menu loop and input handling
├── patients.py       # Patient registration, listing, lookup
├── tests_catalog.py  # Fixed catalog of lab tests and lookup
├── bookings.py       # Bookings, sample collection, reports
├── billings.py       # Bill generation
└── __pycache__/      # Auto-generated by Python (ignore)
```

## Requirements

- Python 3.6 or higher (uses f-strings)
- No third-party libraries

## How to Run

```bash
python main.py
```

## Menu Options

| # | Option              | Description                                        |
|---|---------------------|----------------------------------------------------|
| 1 | Register Patient    | Enter name, age, gender, contact number            |
| 2 | List of Patients    | Show all registered patients                       |
| 3 | View Test Catalog   | Show test IDs, names, prices                       |
| 4 | Book a Test         | Enter patient ID and test ID                       |
| 5 | Collect Sample      | Mark a booking's sample as collected               |
| 6 | Generate a Report   | Enter the result for a booking (sample collected)  |
| 7 | View a Report       | Display patient, test, and result                  |
| 8 | View all Bookings   | List every booking with status                     |
| 9 | Generate a Bill     | Itemised bill for a patient                        |
| 10| Exit                | Quit the program                                   |

## Typical Workflow

1. Register a patient (option 1) → receives ID 1, 2, 3, …
2. Book a test (option 4) → receives a booking ID
3. Collect the sample (option 5)
4. Generate the report with the result (option 6)
5. View the report (option 7)
6. Generate the bill (option 9)

## Data Storage

All data is held in Python lists in memory. **Data is lost when the program exits.**
